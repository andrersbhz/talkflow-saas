# TalkFlow SaaS Starter

Base inicial de uma plataforma SaaS multiatendimento inspirada funcionalmente em ferramentas de atendimento omnichannel, com identidade e implementação próprias.

## Stack
- Next.js + React + TypeScript
- NestJS
- PostgreSQL + Prisma
- Redis / BullMQ
- Docker

## Escopo inicial
- Multiempresa
- Onboarding obrigatório com conexão de número/canal
- Conversas
- Contatos
- Board/CRM
- Chatbots e editor visual de fluxo
- Agentes de IA
- Campanhas
- Relatórios
- Configurações
- Arquitetura preparada para Meta Cloud API, Evolution API, Z-API e outros adapters

Consulte a documentação em `/docs` para arquitetura, API, roadmap e handoff para Google AI Studio.
