# Roadmap

## V0.1 - Fundação
- Monorepo web/api/shared
- Docker PostgreSQL + Redis
- Prisma multi-tenant
- UI base das telas principais
- Onboarding obrigatório de canal
- API de gate/conexão demo
- Documentação de arquitetura

## V0.2 - Núcleo operacional
- Auth JWT + refresh
- RBAC completo
- PrismaService/repositories
- Meta Cloud API Embedded Signup
- Webhook Meta
- Contatos reais
- Conversas/mensagens em banco
- WebSocket realtime
- Upload de mídia

## V0.3 - Atendimento profissional
- Fila, departamentos, round-robin
- transferências, notas internas, tags
- respostas rápidas, horários, SLA
- auditoria e notificações

## V0.4 - Automação
- React Flow
- Versionamento de chatbot
- Runtime de nós/arestas
- condições, delays, webhooks, HTTP requests

## V0.5 - IA
- Gemini provider
- OpenAI/Anthropic adapters
- RAG e bases de conhecimento
- handoff humano

## V0.6 - Campanhas
- Segmentação, templates, agendamento
- workers e rate limiting
- métricas de entrega/leitura/resposta

## V1.0 - Comercial
- Billing/planos
- onboarding de clientes
- observabilidade
- testes E2E
- segurança e hardening
- deploy production-ready
